# Octopye New Site Design

Static GitHub Pages website for Octopye.

## Run locally

From this folder:

```bash
python -m http.server 4181
```

Then open http://127.0.0.1:4181/

No dependency installation is required. The site is static HTML, CSS and JavaScript.

## Deploy

Upload the contents of this folder to the GitHub Pages publishing branch or folder for octopye.com.

## SEO files

- sitemap.xml
- robots.txt
- llms.txt
- llms-full.txt
- JSON-LD schema embedded on every HTML page

## Notes

The redesign follows the positioning: practical digital systems for businesses that want less manual work and better customer journeys. Fixed starting prices are preserved for scoped services; custom systems are scoped after discovery.
